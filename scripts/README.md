# 議事次第メール生成スクリプト

`meeting_agenda_template.html` に、スプレッドシート（Excel または CSV）の会議情報と議題を自動で流し込み、
その月の議事次第メールHTMLを生成します。

## 必要環境

- Python 3.8以降（追加インストール不要。標準ライブラリのみで動作）
- `.xlsx` を直接読み込む場合のみ `pip install openpyxl` が必要

## 使い方

### パターン1：Excelワークブック（.xlsx）から生成

`meeting_data.xlsx` に以下2つのシートを用意する。

**シート「会議情報」**（1行目はヘッダー、A列=項目 / B列=内容）

| 項目 | 内容 |
|---|---|
| 年 | 2026 |
| 月日 | 9/10 |
| 時間帯 | 14:00〜15:00 |
| 場所 | 本社3階 大会議室 |
| 議長 | 営業部 山田 太郎 |
| 記録係 | 鈴木 花子 |
| 出席者 | 山田、鈴木、佐藤、田中 |
| 欠席者 | （空欄可。空欄なら「なし」と表示） |
| 件名 | （空欄可。空欄なら「【○年○月度】定例会議」を自動生成） |

「月日」は `9/10` のように「月/日」形式で入力する（`9-10` でも可）。メール本文には
「2026年9月10日（木）」のように、曜日を自動計算したうえで展開される。項目名を
「月/日」としても同じように読み取れる。

**シート「議題」**（1行目はヘッダー）

| No | 議題 | 説明・論点 | 担当 | 想定時間（分） | 資料/備考 |
|---|---|---|---|---|---|
| 1 | 前回議事録の確認 | 進捗共有 | 鈴木 | 5 | 前回議事録 |
| 2 | 今月の実績報告 | | 山田 | 15 | |

「説明・論点」「資料/備考」は空欄可（空欄の項目はメール本文に表示されない）。
「想定時間（分）」は数値のみ（「5」など。「5分」のように単位を入れても自動で除去される）。

実行:

```bash
pip install openpyxl   # 初回のみ
python3 scripts/generate_agenda_email.py --workbook meeting_data.xlsx
```

### パターン2：CSV2ファイルから生成

`scripts/sample_data/meeting_info.csv` と `scripts/sample_data/agenda_items.csv` をサンプルとして
コピーし、内容を書き換える。

```bash
python3 scripts/generate_agenda_email.py \
  --info meeting_info.csv \
  --items agenda_items.csv
```

Googleスプレッドシートを使っている場合は「ファイル → ダウンロード → カンマ区切り値(.csv)」で
シートごとにCSVを書き出せる。

## 出力

デフォルトでは `output/agenda_<年>-<月>.html` に生成される（`--output` で変更可）。

1. 生成されたHTMLファイルをブラウザ（Chrome等）で開く
2. ページ全体を選択（Ctrl+A）してコピー（Ctrl+C）
3. Gmail/Outlookの新規メール本文に貼り付け（Ctrl+V）
4. 件名・宛先を設定し、内容を確認のうえ送信

## 差し込まれる項目

会社名・署名・事前準備のお願いなど、毎月変わらない項目はテンプレート側に直接編集しておく。
スクリプトが自動で書き換えるのは以下のみ：

- 件名（タイトル）
- 開催日時（年月日から曜日を自動計算）／場所／議長／記録係／出席者／欠席者
- 議題テーブル（行数は自由。CSVやシートの行を追加・削除すればそのまま反映される）

## テンプレートの仕組み

`meeting_agenda_template.html` 内には `<!--F:キー-->値<!--/F-->` という目印（HTMLコメント）が
埋め込まれている。ブラウザ上では見えないため、スクリプトを使わず手動で `○○` を書き換える
従来の運用もそのまま可能。議題テーブルの行は `<!--ROWS:AGENDA:START-->` 〜 `<!--ROWS:AGENDA:END-->`
の間にあるものが丸ごと置き換えられる。
