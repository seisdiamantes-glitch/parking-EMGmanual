# 議事次第・議事録メール生成スクリプト

- `generate_agenda_email.py` … `meeting_agenda_template.html` に会議情報と議題を流し込み、開催前に送る「議事次第」メールHTMLを生成
- `generate_minutes_email.py` … `meeting_minutes_template.html` に会議情報と審議内容・決定事項・アクションアイテムを流し込み、開催後に送る「議事録」メールHTMLを生成

いずれもスプレッドシート（Excel または CSV）から自動で流し込む。「会議情報」シートは両スクリプトで共通の
`meeting_data.xlsx` を使い回せる（議事録側だけで使う項目は議事次第スクリプトからは無視される）。

## 必要環境

- Python 3.8以降（追加インストール不要。標準ライブラリのみで動作）
- `.xlsx` を直接読み込む場合のみ `pip install openpyxl` が必要

## 議事次第メール（generate_agenda_email.py）

### パターン1：Excelワークブック（.xlsx）から生成

`meeting_data.xlsx` に以下2つのシートを用意する。

**シート「会議情報」**（1行目はヘッダー、A列=項目 / B列=内容）

| 項目 | 内容 |
|---|---|
| 年 | 2026 |
| 月日 | 9/10 |
| 時間帯 | 14:00〜15:00 |
| 場所 | 本社3階 大会議室 |
| 議長 | 営業部 山田 太郎 |
| 記録係 | 鈴木 花子 |
| 出席者 | 山田、鈴木、佐藤、田中 |
| 欠席者 | （空欄可。空欄なら「なし」と表示） |
| 件名 | （空欄可。空欄なら「【○年○月度】定例会議」を自動生成） |

「月日」は `9/10` のように「月/日」形式で入力する（`9-10` でも可）。メール本文には
「2026年9月10日（木）」のように、曜日を自動計算したうえで展開される。項目名を
「月/日」「月ノ日」としても同じように読み取れる。

Excelは `8/28` のように入力すると自動的に日付型に変換し「8月28日」のように表示する
ことがあるが、その場合もスクリプト側で自動的に読み替えるため、そのまま入力してよい
（セルの表示形式を「文字列」に変更する必要はない）。

**シート「議題」の見出し行について**：スクリプトはA列が「No」というテキストになって
いる行を自動的に見出し行として探すため、その上にタイトルや開催概要などの行を追加して
も問題ない（見出し行が何行目にあっても構わない）。

**シート「議題」**（1行目はヘッダー）

| No | 議題 | 説明・論点 | 担当 | 想定時間（分） | 資料/備考 |
|---|---|---|---|---|---|
| 1 | 前回議事録の確認 | 進捗共有 | 鈴木 | 5 | 前回議事録 |
| 2 | 今月の実績報告 | | 山田 | 15 | |

「説明・論点」「資料/備考」は空欄可（空欄の項目はメール本文に表示されない）。
「想定時間（分）」は数値のみ（「5」など。「5分」のように単位を入れても自動で除去される）。

実行:

```bash
pip install openpyxl   # 初回のみ
python3 scripts/generate_agenda_email.py --workbook meeting_data.xlsx
```

### パターン2：CSV2ファイルから生成

`scripts/sample_data/meeting_info.csv` と `scripts/sample_data/agenda_items.csv` をサンプルとして
コピーし、内容を書き換える。

```bash
python3 scripts/generate_agenda_email.py \
  --info meeting_info.csv \
  --items agenda_items.csv
```

Googleスプレッドシートを使っている場合は「ファイル → ダウンロード → カンマ区切り値(.csv)」で
シートごとにCSVを書き出せる。

### 出力

デフォルトでは `output/<YYYYMMDD>_meeting_agenda.html`（例：`output/20260828_meeting_agenda.html`）に
生成される。開催日（会議情報シートの年・月日）から自動的に決まるので、月に複数回開催しても
ファイルが上書きされることはない。保存先を変えたい場合は `--output` で指定する。

```bash
python3 scripts/generate_agenda_email.py --workbook meeting_data.xlsx --output どこか別の場所\my_agenda.html
```

1. 生成されたHTMLファイルをブラウザ（Chrome等）で開く
2. ページ全体を選択（Ctrl+A）してコピー（Ctrl+C）
3. Gmail/Outlookの新規メール本文に貼り付け（Ctrl+V）
4. 件名・宛先を設定し、内容を確認のうえ送信

### 差し込まれる項目

会社名・署名・事前準備のお願いなど、毎月変わらない項目はテンプレート側に直接編集しておく。
スクリプトが自動で書き換えるのは以下のみ：

- 件名（タイトル）
- 開催日時（年月日から曜日を自動計算）／場所／議長／記録係／出席者／欠席者
- 議題テーブル（行数は自由。CSVやシートの行を追加・削除すればそのまま反映される）

### テンプレートの仕組み

`meeting_agenda_template.html` 内には `<!--F:キー-->値<!--/F-->` という目印（HTMLコメント）が
埋め込まれている。ブラウザ上では見えないため、スクリプトを使わず手動で `○○` を書き換える
従来の運用もそのまま可能。議題テーブルの行は `<!--ROWS:AGENDA:START-->` 〜 `<!--ROWS:AGENDA:END-->`
の間にあるものが丸ごと置き換えられる。

## 議事録メール（generate_minutes_email.py）

`meeting_minutes_template.html` に、開催後の審議内容・決定事項・アクションアイテムを流し込み、
議事録メールHTMLを生成する。**議事の項目数は毎回変わってよい**——「議事録」シートの行を増減
させれば、そのまま「議題ごとの審議内容」ブロックの数に反映される（1件でも10件でも対応）。
「決定事項」「アクションアイテム」も同様に件数自由で、0件なら「特になし」と表示される。

### パターン1：Excelワークブック（.xlsx）から生成

`meeting_data.xlsx`（議事次第と同じファイルでよい）に以下のシートを用意する。

**シート「会議情報」**：議事次第と共通。加えて以下の項目を空欄可で追加できる。

| 項目 | 内容 |
|---|---|
| 回答期限 | 9/17（木）（空欄可。空欄なら「追ってご案内する期日」と表示） |
| 次回年 | 2026（次回開催が未定なら空欄でよい） |
| 次回月日 | 10/8 |
| 次回時間帯 | 14:00〜 |
| 次回場所 | 本社3階 大会議室 |
| 次回議題 | 今月の実績確認、新規案件の最終決定 |

**シート「議事録」**（1行目はヘッダー、A列が「No」の行を見出し行として自動検出）

| No | 議題 | 報告内容 | 議論・意見 | 結論 |
|---|---|---|---|---|
| 1 | 前回議事録の確認 | 対応状況の報告 | 期限延長の意見 | 期限を9/17まで延長 |
| 2 | 今月の実績報告 | 目標比105％ | | 来月も継続 |

「議題」列はアジェンダの「議題」シートと同じ項目名・順序で記入すると、当日の議事次第に
沿った議事録になる（コピーして使い回してよい）。「報告内容」「議論・意見」「結論」は
いずれも空欄可（すべて空欄の議題は「特記事項なし。」と表示される）。

**シート「決定事項」**（任意。無くても生成できる）

| No | 内容 |
|---|---|
| 1 | 新規案件の対応方針はB案を採用する。 |

**シート「アクションアイテム」**（任意。無くても生成できる）

| No | タスク内容 | 担当 | 期限 | 状況 |
|---|---|---|---|---|
| 1 | 実績報告資料を修正し共有フォルダへ格納 | 山田 | 9/12 | 未着手 |

「状況」は「未着手」「対応中」「完了」のいずれかでバッジの色分けをする（空欄は「未着手」扱い、
それ以外の文言もそのまま表示はされる）。

実行:

```bash
pip install openpyxl   # 初回のみ
python3 scripts/generate_minutes_email.py --workbook meeting_data.xlsx
```

### パターン2：CSVファイルから生成

`scripts/sample_data/meeting_info.csv`・`minutes_items.csv`・`decisions.csv`・`action_items.csv`
をサンプルとしてコピーし、内容を書き換える（`--decisions` `--actions` は省略可）。

```bash
python3 scripts/generate_minutes_email.py \
  --info meeting_info.csv \
  --minutes minutes_items.csv \
  --decisions decisions.csv \
  --actions action_items.csv
```

### 出力

デフォルトでは `output/<YYYYMMDD>_meeting_minutes.html` に生成される。開催日（会議情報シートの
年・月日）から自動的に決まる。保存先を変えたい場合は `--output` で指定する。HTMLをブラウザで開き、
全選択→コピーしてメール本文に貼り付ける手順は議事次第と同じ。

### テンプレートの仕組み

`meeting_minutes_template.html` にも同じ `<!--F:キー-->値<!--/F-->` マーカーが埋め込まれている。
「決定事項」は `<!--ROWS:DECISIONS:START-->`〜`:END-->`、「議題ごとの審議内容」は
`<!--ROWS:MINUTES:START-->`〜`:END-->`、「アクションアイテム」は `<!--ROWS:ACTIONS:START-->`〜
`:END-->` の間がそれぞれ丸ごと置き換えられる。
